### 📂 Key Projects

#### 🎮 [FinanceQuest](https://github.com/KangBin2005/FinanceQuest)

*A gamified financial literacy simulation.*

* **Tech:** Azure OpenAI, LangChain, Python, PyGame, scikit-learn, Matplotlib
* **Focus:** LLM applications, machine learning, and interactive analytics
* **Highlights:** Integrated LLMs to provide personalised financial advice and built an ML model to predict goal achievement.

#### 🏦 [AI Budgeting & Financial Literacy Coach](https://github.com/KangBin2005/LLM-Fine-Tuned-Model-with-Vertex-AI)

*LLM fine-tuning and RAG for financial education.*

* **Tech:** Google Vertex AI, Gemini, Gradio, ChromaDB, GCS
* **Focus:** LLM fine-tuning, RAG, model evaluation, and GenAI applications
* **Highlights:** Fine-tuned a Gemini model and built a side-by-side evaluation interface comparing the fine-tuned and base models.

#### 🧠 Applied Deep Learning — Waste & News Classification

*Deep learning applications across computer vision and NLP.*

* **Tech:** TensorFlow, Keras, VGG16, CNN, BiLSTM, DistilBERT, Hugging Face
* **Focus:** Computer vision, NLP, transfer learning, and transformer fine-tuning
* **Highlights:** Compared custom CNNs against VGG16 for waste classification and BiLSTM against DistilBERT for news classification.

**Key Results:**

* 🖼️ **VGG16:** 81.49% test accuracy on waste classification
* 📰 **DistilBERT:** 94.24% test accuracy on news classification

#### 🏗️ [Singapore Water Quality Medallion Architecture](https://github.com/KangBin2005/Singapore-Water-Quality-Medallion-Architecture)

*End-to-end data engineering and machine learning pipeline.*

* **Tech:** Snowflake, SQL, Streamlit, Python, scikit-learn
* **Focus:** Data engineering, ML, and analytics
* **Highlights:** Designed a Bronze–Silver–Gold data architecture processing 80+ PUB parameters and developed a Random Forest model with a Streamlit analytics dashboard.

#### 🏠 [HDB Resale & Amenity 360° Analytics Dashboard](https://github.com/KangBin2005/D3.js-HDB-Resale-Price-Analysis-Dashboard)

*Interactive geospatial data visualisation.*

* **Tech:** D3.js, JavaScript, HTML5, CSS3, Bootstrap 5
* **Focus:** Geospatial analytics and interactive visualisation
* **Highlights:** Built a map-based dashboard with linked cross-filtering across five visualisations and 1km amenity proximity analysis.

#### 🛒 [Product Sentiment Analysis](https://github.com/KangBin2005/TSAP)

*Sentiment analysis for e-commerce product reviews.*

* **Tech:** SeleniumBase, NLTK, scikit-learn, Python
* **Focus:** Web scraping, NLP preprocessing, and classification
* **Highlights:** Automated the collection of 5,000+ reviews and developed an NLP preprocessing and sentiment classification pipeline.
